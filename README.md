# ☕ Coffee Shop Sales Dashboard

An interactive Excel dashboard built to analyze coffee shop sales data and transform raw transactional data into meaningful business insights. This project demonstrates my ability to clean, organize, analyze, and visualize data using Microsoft Excel.

---

## 📌 Project Overview

The objective of this project was to analyze coffee shop sales across multiple store locations and identify patterns in customer behavior, product performance, and revenue trends.

Using Excel's analytical features, I created a fully interactive dashboard that allows users to explore sales performance through filters and dynamic visualizations.

---

## 🎯 Objectives

* Analyze overall sales performance.
* Track monthly and daily sales trends.
* Identify peak business hours.
* Compare sales across store locations.
* Understand product and category performance.
* Build an interactive dashboard for quick business decision-making.

---

## 🛠️ Tools & Excel Features Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Lookup Functions (VLOOKUP)
* Data Validation (Drop-down Lists)
* Slicers
* Interactive Dashboard Design

---

## 📊 Dashboard KPIs

The dashboard includes key business metrics such as:

* Total Sales
* Total Transactions
* Best Product Type
* Best store location
  ---

## 📈 Dashboard Visualizations

The dashboard provides interactive visualizations including:

* Sales by Product Category
* Top Selling Products
* Sales by Day of Week
* Hourly Sales Distribution

Users can interact with the dashboard using slicers and dropdown menus to dynamically filter the data.

---

## 🔍 Data Analysis Process

### 1. Data Preparation

* Reviewed the raw dataset for completeness.
* Organized transactional data into a structured format.
* Verified data consistency before analysis.

### 2. Data Analysis

Created Pivot Tables to summarize:

* Sales by month
* Sales by store location
* Product category performance
* Product-wise sales
* Customer purchasing trends
* Transaction counts

### 3. Dynamic Reporting

Used lookup functions and formulas to retrieve dynamic values and automate KPI calculations.

Implemented:

* Lookup functions
to create flexible and reusable reports.

### 4. Dashboard Development

Designed an interactive dashboard using:

* Pivot Charts
* KPI Cards
* Slicers
* Drop-down Filters

The dashboard enables users to explore the data without modifying the underlying dataset.

---

## 💡 Key Business Insights

Some insights generated from the dashboard include:

* Identified peak sales hours to support staffing decisions.
* Compared store performance to identify high-performing locations.
* Determined best-selling products and product categories.
* Analyzed weekday and weekend sales patterns.
* Identified opportunities to improve revenue during low-performing periods.
